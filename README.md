# Hero Waves

A mobile-first, wave-based arena survivor in a single self-contained HTML file (no dependencies).

## Play
Open `index.html` in any browser (or via GitHub Pages). Best in portrait on a phone.

- **Move:** drag anywhere on screen (virtual joystick), or WASD / arrow keys / mouse drag on desktop.
- **Attack:** automatic.
- **Abilities:** 2 abilities + 1 ultimate per hero (buttons bottom-right, or Q / E / R). Ultimates charge from kills.
- **Shop:** spend coins between waves. **Mute:** speaker icon or M.
- **Heroes:** Iron Man (repulsor bolts), Captain America (bouncing shield), Thor (chain lightning), Spider-Man (slowing webs), Hulk (shockwave smash).
- Survive each wave, then pick 1 of 3 upgrades (keys 1-3 on desktop). Boss every 5 waves. Best wave is saved locally.
